## ◈ Featured Projects

</div>

<details>
<summary><b>⬡ e2SoLo Web Application Platform</b> — Enterprise Supply Chain Automation</summary>

<br/>

A full-stack, enterprise-grade web application platform built to automate end-to-end supply chain operations at **e2open**, one of the world's leading supply chain management companies. The platform orchestrates complex business processes — from Excel file ingestion and async task queuing to UiPath bot execution and audit-ready output generation — serving enterprise clients at scale.

| Attribute | Details |
|:---|:---|
| **Stack** | Python, Django, Celery, Redis, React.js, HTML, Tailwind CSS, JavaScript, Oracle SQL, UiPath |
| **Scale** | Enterprise-grade, multi-tenant, production deployment |
| **Architecture** | Async task queue (Celery + Redis), modular Django views, separated read/write DBs |
| **Automation** | UiPath bot triggers via Excel upload → record enqueue → downstream bot execution |
| **Workflow** | Status tracking: Initialized → In-Progress → Success / Failure |
| **Storage** | Automated output file uploads to cloud storage buckets |
| **DB Optimization** | Read-only internal content DB separated from Oracle SQL write DB |
| **Impact** | Eliminated manual processing, improved operational efficiency and audit traceability |

**Key Engineering Decisions:**
- Architected asynchronous task execution using **Celery workers backed by Redis** to handle concurrent enterprise workloads without blocking the main application thread
- Designed a **modular template and view layer** with Tailwind CSS for pixel-perfect, responsive interfaces that non-technical operations staff can use effectively
- Implemented a **UiPath automation trigger system** allowing end users to upload Excel files that automatically enqueue records and initiate downstream bot execution — fully replacing a manual, error-prone process
- Established **audit-friendly status pipelines** with clear state transitions and automated cloud storage uploads for compliance-ready output artifacts
- Optimized database performance by **separating read-only internal content queries** from transactional Oracle SQL write operations, reducing DB contention at scale

</details>

<details>
<summary><b>⬡ ECCN Treeview Extraction & Compliance Automation</b> — UiPath RPA Pipeline</summary>

<br/>

A fully automated compliance validation system built with **UiPath** to replace a labor-intensive manual process of extracting, comparing, and reporting on ECCN (Export Control Classification Number) hierarchical data. The automation interfaces directly with enterprise applications, navigates complex treeview structures, and generates audit-ready Excel reports for compliance teams.

| Attribute | Details |
|:---|:---|
| **Stack** | UiPath, Excel Automation, Oracle SQL, Enterprise Application UI Automation |
| **Domain** | Export Control Compliance, Regulatory Reporting |
| **Scope** | Full replacement of manual ECCN comparison workflow |
| **Intelligence** | Dynamic logic for context-aware database record selection |
| **Output** | Audit-ready Excel reports with highlighted discrepancies |
| **Impact** | Near-zero manual effort, reduced processing time, scalable compliance validation |

**Key Engineering Decisions:**
- Developed **dynamic selector logic** within UiPath to navigate hierarchical treeview structures in enterprise applications, handling variable depth and structure without hardcoded paths
- Built **intelligent database query logic** to dynamically select the appropriate dataset for each ECCN record, ensuring precise and context-aware data retrieval
- Designed an **automated comparison engine** that cross-references extracted treeview data against database records and highlights discrepancies directly in the output Excel report
- Delivered a solution that **scaled validation capacity** for compliance teams, enabling review of significantly more records with higher accuracy and in a fraction of the previous time

</details>
